# ContacNeed en Netlify

El despliegue de **contacneed.com** usa una carpeta base dentro de este repo.

## Carpeta del proyecto

`ContacNeed - Arquitectura Modular Diamante Estabilizada`

## Guía completa

Lee el archivo:

`ContacNeed - Arquitectura Modular Diamante Estabilizada/NETLIFY.md`

## Resumen rápido (Netlify UI)

- **Base directory:** `ContacNeed - Arquitectura Modular Diamante Estabilizada`
- **Build command:** `npm run build`
- **Publish directory:** `dist/client`
- **Functions:** `netlify/functions`

No cambies el build de la raíz del repo si este sitio Netlify sigue sirviendo el ecosistema CMS VIAM (`index.html`, etc.).
